# Bug Report

## Bug ID
BUG_001

## Title
Calculator displays "NaN" when dividing 0 by 0.

## Module
Division

## Steps to Reproduce
1. Open the calculator.
2. Enter 0.
3. Click ÷.
4. Enter 0.
5. Click =.

## Actual Result
The calculator displays **NaN**.

## Expected Result
The application should display a user-friendly error message such as:
"Cannot divide by zero."

## Severity
Medium

## Priority
Medium

## Status
Open
